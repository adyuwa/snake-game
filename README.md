# 🐍 貪吃蛇 Snake — PWA

經典貪吃蛇遊戲，支援手機觸控操作，可加入桌面作為 App 使用。

🎮 **[點此開始遊戲](https://你的帳號.github.io/snake-game/)**

## 功能
- 觸控方向鍵 + 滑動手勢控制
- 難度選擇（慢/中/快）
- 特殊加分食物
- 最高分記錄
- 離線也能玩（PWA Service Worker）
- 可加入手機桌面，全螢幕啟動

## 加入桌面方法
**Android（Chrome）**：開啟網址 → 右上角 `⋮` → 「新增至主畫面」  
**iPhone（Safari）**：開啟網址 → 下方分享鍵 → 「加入主畫面」
